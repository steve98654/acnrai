# Accenture × Faculty co-brand marks

These are the four marks chosen from concept 01, the chevron crossbar. The Accenture ">" takes the place of the crossbar on a Faculty-style S-stroke.

| Folder | Mark |
|---|---|
| `01A-master-lockup/` | Tapered S-stem with chevron crossbar, FACULTY beneath |
| `01D-integral-stem/` | TeX integral sign as the stem, chevron crossbar |
| `01E-risk-to-trust/` | Bounded integral from *risk* to *trust* of d*AI* |
| `01I-cobrand-lockup/` | accenture, divider, integral mark and FACULTY |

Each mark comes in four styles. Every style is available as PDF and SVG (vector) and as a 600 dpi PNG.

- `_dark`: white on near-black (#09090B), with padding
- `_light`: black on white, with padding
- `_white`: white on a transparent background
- `_black`: black on a transparent background

The chevron is always Accenture purple #A100FF. The gap around the chevron is a real cut in the stem, so it holds on any background.

To rebuild, run `src/build.sh`. It needs pdflatex (TeX Live with lmodern) and poppler-utils. The source is `src/logos.tex`.

These are original vector drawings made for internal review. They are not official artwork of either firm, and any external use needs sign-off from both brand teams.
